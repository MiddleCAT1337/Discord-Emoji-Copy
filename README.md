# Discord Emoji Copy

โปรแกรมบรรทัดคำสั่ง (CLI) สำหรับดึงรายการอีโมจิจากเซิร์ฟเวอร์ Discord แล้วบันทึกเป็นไฟล์รูปลงในโฟลเดอร์บนเครื่องของคุณ อีโมจินิ่งจะเป็นไฟล์ webp ส่วนอีโมจิที่ขยับได้จะเป็น gif ชื่อไฟล์ใช้ชื่ออีโมจิบน Discord ถ้าชื่อซ้ำหรือใช้บน Windows ไม่ได้จะปรับให้อัตโนมัติ

## ฟีเจอร์

- ดึงรายการอีโมจิของเซิร์ฟเวอร์ผ่าน Discord API v10
- ดาวน์โหลดหลายไฟล์พร้อมกันด้วย worker 16 ตัว
- สร้างโฟลเดอร์ชื่อตาม Server ID แล้วเก็บไฟล์ไว้ข้างใน
- แสดงสถานะทีละอีโมจิ (OK หรือ FAIL) และสรุปจำนวนตอนจบ

## เทคโนโลยีที่ใช้

- ภาษา: Go 1.22
- ไลบรารีมาตรฐาน: net/http, encoding/json, sync

## สิ่งที่ต้องมีก่อนติดตั้ง

- Go เวอร์ชัน 1.22 ขึ้นไป (เช็กด้วยคำสั่ง go version)
- บัญชี Discord ที่เข้าเซิร์ฟเวอร์เป้าหมายได้ และมี User Token ที่ใช้เรียก API ได้
- Server ID (ตัวเลข snowflake ประมาณ 17–20 หลัก) ของเซิร์ฟเวอร์ที่ต้องการ copy อีโมจิ

หมายเหตุด้านความปลอดภัย: User Token คือรหัสลับของบัญชี ห้ามใส่ใน README หรืออัปโหลดขึ้น GitHub ถ้า token หลุดให้รีเซ็ตหรือเปลี่ยนรหัสผ่านทันที การใช้ token กับเครื่องมือภายนอกอาจขัดกับข้อกำหนดของ Discord ใช้เพื่อการเรียนรู้หรือสำรองข้อมูลของตัวเองเท่านั้น

## วิธีติดตั้ง

1. เปิดเทอร์มินัลแล้วไปที่โฟลเดอร์โปรเจกต์ (โฟลเดอร์ที่มีไฟล์ main.go)

2. ดาวน์โหลด dependency ของ Go (โปรเจกต์นี้ใช้แต่ไลบรารีมาตรฐาน แต่รันคำสั่งนี้เพื่อให้แน่ใจว่า module พร้อม)

```bash
go mod download
```

3. คอมไพล์เป็นไฟล์รันได้ (Windows จะได้ discord-emoji-copy.exe ถ้าตั้งชื่อแบบนี้)

```bash
go build -o discord-emoji-copy .
```

ถ้าไม่ต้องการไฟล์ exe แยก ข้ามขั้นนี้แล้วใช้ go run ในหัวข้อวิธีใช้งานได้เลย

## วิธีใช้งาน

### หา Server ID

1. เปิด Discord บนเดสก์ท็อป
2. ไปที่ Setting แล้วเปิด Developer Mode
3. คลิกขวาที่ไอคอนเซิร์ฟเวอร์ที่ต้องการ แล้วเลือก Copy Server ID
4. วาง ID ที่ได้ไว้ ต้องเป็นตัวเลขล้วน ไม่มีช่องว่าง

### เรื่อง User Token

โปรแกรมถาม User Token ตอนรัน วิธีหา token มีหลายแบบบนอินเทอร์เน็ต แต่ทุกแบบมีความเสี่ยง ถ้าไม่แน่ใจอย่าแชร์ token ให้ใคร และอย่า commit ลง git

บัญชีของคุณต้องมองเห็นอีโมจิของเซิร์ฟเวอร์นั้นได้ ถ้า API ตอบ 403 หรือ 401 มักเป็นเพราะ token ผิด หมดอายุ หรือไม่มีสิทธิ์ในเซิร์ฟเวอร์

### รันโปรแกรม

วิธีที่ 1 รันตรงๆ ด้วย Go

```bash
go run .
```

วิธีที่ 2 ถ้าคอมไพล์แล้ว (Windows)

```bash
.\discord-emoji-copy.exe
```

วิธีที่ 3 ถ้าคอมไพล์แล้ว (Linux หรือ macOS)

```bash
./discord-emoji-copy
```

### กรอกค่าตามที่โปรแกรมถาม

1. บรรทัด User Token: วาง token แล้วกด Enter (ตอนพิมพ์อาจไม่เห็นตัวอักษร เป็นเรื่องปกติของบางเทอร์มินัล)
2. บรรทัด Server ID: วาง Server ID แล้วกด Enter

ตัวอย่างลักษณะหน้าจอ (token เป็นตัวอย่าง ไม่ใช่ของจริง)

```
User Token: your_token_here
Server ID: 123456789012345678
Downloading 42 emoji(s) into 123456789012345678/ ...
OK   pepeHappy
OK   catWiggle
...
Done: 42 ok, 0 failed (total 42)
```

### ผลลัพธ์ที่ได้

- โปรแกรมสร้างโฟลเดอร์ชื่อเดียวกับ Server ID ในโฟลเดอร์ที่คุณรันคำสั่ง
- ข้างในมีไฟล์รูป เช่น ชื่ออีโมจิ.webp หรือ ชื่ออีโมจิ.gif
- ถ้าเซิร์ฟเวอร์ไม่มีอีโมจิ จะขึ้นข้อความ No emojis on this server. แล้วจบ
- ถ้าดาวน์โหลดบางไฟล์ไม่สำเร็จ จะมี FAIL บน stderr และ exit code เป็น 1

### ข้อผิดพลาดที่เจอบ่อย

- Error: token is required คือกด Enter ตอน token ว่าง
- Error: server ID must be a numeric snowflake คือ ID ไม่ใช่ตัวเลขหรือความยาวไม่ตรง
- discord api 401 หรือ 403 คือ token หรือสิทธิ์ไม่ผ่าน ลอง token ใหม่หรือเช็กว่าอยู่ในเซิร์ฟเวอร์
- FAIL ชื่ออีโมจิ คือ CDN หรือเครือข่ายมีปัญหา ลองรันใหม่

## โครงสร้างโปรเจกต์

```
  README.md     ไฟล์นี้
```
